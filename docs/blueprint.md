# **App Name**: Reflections in Glass

## Core Features:

- Art Gallery: Display high-quality images of glass art pieces in a visually appealing gallery format.
- Art Descriptions: Provide detailed descriptions of each art piece, including the artist's inspiration and techniques.
- Filtering and Sorting: Allow users to sort and filter art pieces by category (e.g., sculptures, vases, decorative items).
- Contact Form: Enable users to contact the artist directly via a contact form for inquiries or purchase requests.
- Style Match: AI powered 'style match' tool. If a user uploads an image of a room, recommend glass art pieces to match, using generative AI to determine compatibility of style.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to convey sophistication and artistry, reminiscent of deep blue glass.
- Background color: Very light gray (#F0F0F0), almost white, for a clean, modern, gallery-like feel that does not compete with the colorful art.
- Accent color: Soft Gold (#D4AF37) to highlight interactive elements and add a touch of elegance.
- Body text and headline: 'Alegreya', a serif, to convey an elegant, intellectual, contemporary feel.
- Use simple, minimalist icons to represent filter options and navigation.
- Employ a clean and spacious layout with generous spacing between art pieces and text, similar to that used by upscale creative agencies. Use subtle shadows to emphasize content sections.
- Implement smooth transitions and subtle animations when loading images or navigating between art pieces. Gentle fades for transitions; use a Ken Burns effect on featured imagery.
